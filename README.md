# Fill the Jars — Sensory Calm-Down Timer

A gentle, interactive timer built for autistic children who need a calming activity when they're overstimulated.

## Why this exists
Autistic children often experience time differently — abstract concepts like "five more minutes" don't carry much weight unless tied to something they can see and process, and this "time blindness" can add anxiety on top of sensory overload. Occupational therapists frequently recommend visual timers for exactly this reason: they turn an invisible, abstract countdown into something concrete a child can watch unfold, which research and clinical practice link to reduced transition anxiety and better self-regulation.

This project applies that same principle in a softer, more sensory-friendly form — colorful jars filling with water instead of a shrinking disk or numbers — so it doubles as both a timer and a calming visual to focus on during overstimulation.

## How it works
- A grown-up sets a duration (minutes/seconds).
- A row of colorful glass jars fills one at a time, drop by drop, at a steady, predictable pace.
- Each finished jar gets a small checkmark before the next one starts.
- When the last jar is full, a soft splash celebrates that time is up.
- Dark theme with a soft glowing water effect keeps the visual stimulation gentle rather than jarring.

## Design choices, backed by what works for autistic kids
- **No countdown numbers or percentages** — many autistic children don't reliably read numeric time as "time passing," so the fill level itself is the cue, the same logic behind shrinking-disk visual timers.
- **Predictable, steady pacing** — consistent, non-sudden motion is calming and builds trust that a routine will play out the same way every time, which reduces anxiety around transitions.
- **No sound by default** — respects sensory sensitivities; sound can be added by a caregiver if a child responds well to it, but it's never forced.
- **Minimal UI** — one input, then nothing to manage. Less visual clutter to process during an already overstimulating moment.
- **Segmented progress (multiple jars, not one countdown)** — mirrors how color-coded, segmented visual schedules help children anticipate what's coming and feel a sense of control.
